# Keroles Aziz Masry — Developer Profile

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy to GitHub Pages
1. Create or open the repository you want to publish.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

You can also deploy the folder to Vercel or Netlify as a static site.

## Features
- Responsive layouts for mobile, tablet and desktop
- Accessible mobile navigation
- Dark/light theme toggle (preference saved locally when browser storage is available)
- Project category filters
- Scroll reveal animations with reduced-motion support
- Working email, phone, GitHub, LinkedIn, and supplied project links
- SEO description, social preview metadata, and favicon
